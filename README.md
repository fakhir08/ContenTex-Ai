# ContentX AI MVP

Prototype aplikasi AI Content Growth Agent.

## Yang sudah ada
- Dashboard
- Upload video
- Input analytics
- Simulasi AI content score
- Winning pattern
- Generate 10 konten
- Script angle, hook, shot list, caption, CTA, target leads
- Content calendar
- Sales funnel

## Catatan penting
Ini adalah MVP frontend/prototype. Analisis AI sungguhan membutuhkan backend dan API model AI, speech-to-text, penyimpanan video, autentikasi, serta database.

## Menjalankan
Buka `index.html` di browser.

## Tahap berikutnya
1. Next.js/React production app
2. Supabase Auth + PostgreSQL + Storage
3. Backend upload & video processing
4. Speech-to-text
5. AI orchestration
6. Persistent Content DNA / AI memory
7. TikTok/YouTube analytics integration jika API/access yang diperlukan tersedia
8. Subscription & payment
